:::note
Swift and Objective-C are supported for Flopper with XCFramework and Swift Package Manager as the primary Apple distribution mechanism.
:::

## Swift Package Manager

Build the Apple artifact from the repository root:

```bash
./gradlew :flopper-ios:assembleFlopperKitKmpXCFramework
swift package describe
```

The local package manifest points to the generated XCFramework at:

```bash
flopper-ios/build/XCFrameworks/release/FlopperKitKmp.xcframework
```

For Xcode wrapper applications built from Kotlin Multiplatform, keep the normal
`embedAndSignAppleFrameworkForXcode` build phase and add the generated framework
to the app target if you need a direct Apple-side dependency.

For external Apple apps, consume the generated `Package.swift` from a release
artifact where `FlopperKitKmp.xcframework.zip` is published as a Swift Package
`binaryTarget`.

## Kotlin Multiplatform client

The KMP entrypoint lives under `flopper-native` and exposes a common API:

```kotlin
val client = FlopperClient.create(
  FlopperConfig.Ios(
    appName = "MyApp",
  ),
)
client.start()
```

Use `FlopperConfig.Android(contextHandle = applicationContext)` on Android and
share plugin definitions from `commonMain`.

## Enabling plugins

Finally, you need to add plugins to your Flipper client. The Layout Inspector plugin is shown above to get you started.
See [Network Plugin](../setup/plugins/network.mdx) and [Layout Inspector Plugin](../features/plugins/inspector.mdx) for information on how to add them and enable Litho or ComponentKit support. You can check the sample apps in the [GitHub repo](https://github.com/facebook/flipper) for examples of integrating other plugins.
